# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, critique code rather than people, and keep discussions welcoming to newcomers and to people writing in English or Spanish.

To report unacceptable behavior, contact the maintainer privately through their GitHub profile. Reports are handled confidentially.
